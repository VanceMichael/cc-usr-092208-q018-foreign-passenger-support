# 外籍旅客身份服务接续

帮助外籍铁路旅客在购票、进站和退改渠道间安全接续身份服务。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括外籍铁路旅客、车站服务人员、铁路客服中心、隐私合规人员。

资料所依据的领域事实如下：

- 铁路部门适应过境免签带来的客流增长
- 全国铁路发送外籍旅客同比显著增长
- 铁路部门为外籍旅客出行提供便利

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
