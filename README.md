# 外籍旅客身份服务接续

帮助外籍铁路旅客在购票、进站和退改渠道间安全接续身份服务。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括外籍铁路旅客、车站服务人员、铁路客服中心、客服与隐私负责人。

资料所依据的领域事实如下：

- 外籍旅客从线上客服转到车站窗口时，不应再次解释护照姓名顺序、拉丁字符转写或证件换发经过
- 工作人员手工合并身份记录可能错退他人车票，退改不得仅凭手工合并办理
- 经本人同意，铁路客服可接续证件版本、核验结果、购票身份、行程关联、多语种求助和人工处置记录
- 与本次出行无关的签证资料不予复制
- 姓名近似、同行家庭、跨境行程和离线窗口补录采用审慎规则，低置信度转人工确认
- 证件更新或授权撤回后，车站窗口仍只能看到必要信息
- 旅客可跨渠道延续同一请求；错误合并、越权查阅和超期保留应被发现
- 每笔退改结果都应能查回真实授权与核验过程

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
